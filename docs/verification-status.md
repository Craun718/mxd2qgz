## 软件与输入身份

`14772f8e3fedca8e1760bef77ab418011df4d8105f5159a05bc866bf603e3738`。
本轮诊断命令可以读其 OLE 容器和流；这不确认保存版本、图层数或语义。
未在 ArcMap 中打开，实际打开用 ArcMap 完整版本无记录，图层树、连接、CRS、
范围、样式、标注及布局均**人工未验证**。静态研究的 Desktop 10.8.0.12790 DLL
身份不能替代实际打开样本的软件版本或结果。

QGIS 为本机 `4.2.3-Belém do Pará`（40203，开发版本标记 exported），其他依赖
版本和无敏感基准摘要见 `qgis-output.md`。仅以 offscreen API 读取基准和构造
模型输出，没有打开 GUI 进行目视检查。API 核对图层数、顺序、分组、可见性、
合成点加载、断链保留、CRS、默认范围及属性；这些检查通过。
没有生成从参考 MXD 实际转换的 QGZ，不声称真实源工程可用或视觉一致。
