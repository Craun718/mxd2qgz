## 结构与样本业务值

LELP 版本 short 后的读取序为：String；short；版本 >1 时 short；double；int32；short×2；int32；double×2；short；String×2；四个对象槽；double×2；int32×2；版本 >2 的 IGraphicsContainer 槽；其后版本门字段。版本上限为 7。此处“序”由 10.1.0.3035 `LELP::Load` 静态反编译支持；字段的业务名称并不能由偏移或类型推出。

参考样本的 LELP 键 60 位于 `/Maps:0xb1c`，版本 7。现有逐字段走查记录：首个 String 为 `[JZDH]`，另一 String 为 `默认`；样本中的这些值只证明字节/字符串取值，不证明前者必为标注表达式或后者必为标注类名。版本 7 下可观察到的数字字段与相邻嵌套对象顺序，见现有 [LELP 体逐字段记录](arcmap-10.1-featurelayer-tail.md#lelp-体labelplacementdll-0x785468c0证据确定的)。不要把字符串内容本身作为业务字段命名证据。

LELP ㉔ 请求 IID 经原生常量和类型库复核为 esriCarto `IGraphicsContainer` `{D09411D1-4BB4-11D1-B6CC-080009B996CC}`。样本对应槽 `0xf43..0xf52` 为 16 字节零，即空对象标记；因此没有可供该样本读取的实现类或体。候选实现者位于尚未完整分析的模块，当前证据既不能指定某个实现类，也不能给出其体布局。

LELP ㉖ 本身是 int32 标量；TODO 所指 ISymbol 槽实际是 FeatureLayer 后继段的符号槽。当前符号分派覆盖已有闭合类，并已纳入 TextSymbol；样本槽出现 SimpleMarkerSymbol（类体已闭合）。既有类清单并非 10.1 全部 ISymbol 实现类的完备证明，因而不能推断未知实现不存在或已支持。
