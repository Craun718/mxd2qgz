# ArcMap 版本与对象读取的运行取证

适用于 TODO「MXD 解析」中需要实际运行 ArcMap 的条目。静态调用链、构造输入、安装介质模板均可以辅助定位；只有实际运行观察才可用于勾选对应运行项。使用已安装并授权的 ArcMap 10.1；10.8 单列作兼容性对照。记录实际产品版本、构建号、界面语言及许可环境是否能正常打开工程，勿记录许可密钥。

| 验证项 | 操作和应保存的观察 |
| --- | --- |
| 10.1 头部读写与版本映射 | 用不含敏感路径的最小工程，从同一未修改副本每次独立「另存为」，逐个选择界面实际提供的目标版本。记录选择项、成功/失败、输出文件摘要及 `/Version` 的文本、short、条件字段和剩余字节；随后用 ArcMap 重开各文件。不可用的保存选项标记为未覆盖。 |
| 索引输出、SaveAs UI→put、旧档打开时是否改写索引 | 在与静态地址表一致的构建上，记录已知版本属性的写入/读取点和模块相对地址。在打开旧档前后以及另存选项确定后分别读出索引，保留调用栈、输入选项与落盘值。CLI 的候选索引只是交叉对照，不能代替内存属性观察。 |
| 本地化与未知尾部 | 同一构建和工程、改变一个界面语言条件后重复同一种保存选项。对照落盘版本文本与重新打开结果。发现非空尾部时先记录头部终点、完整流长度及触发条件，再追读取或跳过该区间的调用者。 |
| 10.8 跨版本兼容 | 记录 10.1 和 10.8 相互打开同一测试工程的结果；只在目标环境实际提供的存盘格式下另存、重开。分别记录版本文本、头部回填值和失败阶段。软件版本与磁盘格式版本分别记录。 |
| 对象流重复键及失败处理 | 在隔离的受控工程读取或最小原生测试入口观察引用表写入、后续按键回引及 HRESULT。区分普通回引（命中现有键）与真正替换（已登记键更新其关联对象）；不把构造的 Rust 引用表用例当作原生替换。 |

在仓库内将取得授权的对照文件放入忽略的 `temp/`，保留源文件不动。可用以下命令对照；输出是候选解析，不是运行证据：

```sh
cargo run -- version 'temp/arcmap-runtime/current.mxd'
cargo run -- extract 'temp/arcmap-runtime/current.mxd' /Version 'temp/arcmap-runtime/current.version.bin'
cargo run -- compare 'temp/arcmap-runtime/current.mxd' 'temp/arcmap-runtime/older.mxd' /Version
```

每项记录：软件版本、操作或触发点、样本哈希、流名称与字节范围、预期与观察、未覆盖分支。原始工程、流文件和诊断可能有真实路径或地理信息；仓库只保留脱敏后的证据摘要。
