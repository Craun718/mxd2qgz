# Map 版本 33 集合与槽位读取（2026-11-18）

## 目标与边界

从现有 Map 后缀解析器停点 `/Maps:0x253c9` 继续，处理 Map 架构版本 `>=33`
的数据，直到版本 `>=34` 数据块第一字段之前。实现保留对象头里的类标识和键，
仅跨过空槽及已登记键回引；未知新对象体无外部长度，故在其对象头起点保守停止。

## ArcMap 10.1 证据

- 目标为 Map.dll 10.1.0.3035，SHA-256
  `1c0675cc3a99692686a2e9dd8aaa92a68a94b48e9419d8477e33bb57634b1bb8`；地址为
  静态映像地址。反编译成果 `Map/793ff4d0.c`、`Map/79401850.c` 位于本机
  `/home/gxrs/文档/source/arcmap10.1/`。
- 原始 Load 指令 `0x79400959..0x79400a10`：`cmp cx, ax` 的 CX=`0x21`，紧随
  `jg 0x79400a9a`。有符号条件仅在版本 `<33` 时跳过；`>=33` 落入
  `0x7940096a`，读取 4 字节有符号计数。
- `0x794009bd` 将请求 IID `{00000000-0000-0000-C000-000000000046}`（IUnknown）
  传给 `LoadObject`，每项随后通过集合虚调用加入 Map+`0x1c8`。计数循环结束后，
  `0x79400a16` 读取 4 字节到 Map+`0x1b4`（LONG）；`0x79400a31` 以 IID
  `{E6BDAA75-4D35-11D0-98BE-00805F7CED21}`（IMap）调用 `LoadObject`，目标槽为
  Map+`0x1b8`。
- `0x79400ab0..0x79400ab9` 才比较版本 `0x22`（34）。版本 `>=34` 数据块首个
  流读取在 `0x79400abf..0x79400ad1`，读取 4 字节至 Map+`0x1d0`。因此本模块在
  IMap 槽后停下，不触碰版本 34 块。
- Save `Map/79401850.c` 对应顺序写 Map+`0x1b4` 的 4 字节、+`0x1b8` 对象，
  后续写 +`0x1d0` 的 4 字节、+`0x1d8` 的 8 字节、+`0x1e0` 与 +`0x1e4` 对象。
  Save 侧印证字段相邻顺序，但版本门和读取流程以 Load 指令为主证据。

## 参考样本推进

`samples/测试底图.mxd` 的 `/Maps` 对象版本为 51。由 `/Maps:0x253c9` 开始：

| 偏移 | 读取结果 |
| --- | --- |
| `0x253c9` | IUnknown 集合计数 `0` |
| `0x253cd` | LONG 原始值 `0` |
| `0x253d1` | IMap 空槽（16 字节零类标识） |
| `0x253e1` | 版本 `>=34` 数据块首字段前停止 |

解析器因此把样本 Map 尾部停点从 `0x253c9` 推进至 `0x253e1`。没有对 `0x253e1`
之后的样本字节赋字段名或对象含义。

## 实现、事务与限制

新增未接线模块 `src/maps/map_persist_collections.rs`。负计数、计数上限超限及截断
返回错误，且整个函数不改变 Reader 或引用登记表。对于未知新对象，只提交此前
完整的集合项；未知对象头及其键登记回滚，停止位置为该头起点。IMap 槽按流内
对象头分类，不借 IID 请求值推断 coclass 类标识。

独立测试覆盖参考样本推进、空槽、回引、未知新对象停止与键回滚、坏计数/截断
事务以及版本门。未运行 ArcMap 10.1，也未做 QGIS 人工目视验收；本模块只证明
已核实流结构的安全子集。
