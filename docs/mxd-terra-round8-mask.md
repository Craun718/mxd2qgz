# 第八轮：LayerMasking 非空结构与安全边界（2026-11-17）

本轮增量复核已有静态导出，不重复此前 Map 字段及空集合结论。Map.dll 与 LayerLib.dll 均为 PE x86，文件版本 10.1.0.3035；本轮重算 SHA-256 分别为 `1c0675cc3a99692686a2e9dd8aaa92a68a94b48e9419d8477e33bb57634b1bb8`、`55514f054c9e4827d773cf1a9b9a83e7c41c483f73758965244625165f330e02`。后者资源名为 LayerUI，见 [前轮身份记录](mxd-terra-nextpass-tail.md)。静态导出来自隔离 Ghidra 12.2；LayerLib 两函数反编译有重启上限警告，Map 函数有不可达块警告；不是执行证据。

## 新增边界和实现

- 对照 `temp/terra-nextpass-tail/0x786f1ff0.c` 与 `0x786f1a30.c`：外层每条为对象、内层 int32 数量和相应数量的对象；版本大于 1 时每个内层对象后还有一个 AfCore String，循环结束后读 short。新增 `layer_masking` 读取器覆盖版本 0–2、空引用及已登记键回引、两个计数、版本 2 字符串和尾 short；字符串取现有普通写出子集。类接口兼容性与回引目标的类未验证，结果仅为流结构。未知新对象体无长度，必须整体回退，不能以对象头代替完整对象。负计数、版本负数位模式、资源超限被安全子集拒绝，不等同原生所有行为。
- `0x786f1ff0` 入口直接检查接口空指针并成功返回；Map 的 `0x79403bc0` 也在空接口时不调用 Load。因此提供显式接口状态的读取入口，无接口时消费零字节；不能从流前缀或图层数猜测接口状态。`0x79403d50` 的反编译输出将调用参数简化为常量空指针，伴随多处移除不可达块警告，不能据此断言所有图层均无接口；需要结合汇编、实际类接口或运行取证补证。
- `map_object` 的 Map 自身遮罩集合已接入非空结构子集；在完整集合后的 short 继续沿用现有字段，`mxd_maps` 诊断报告条目数。由于逐图层接口状态未知，仍停在逐图层入口，保留后续所有字节。读取器对集合、对象登记、未知新体和截断采用事务回退；Map 集成保留此前逐字段提交规则。
- 根尾部必须在所有 Map 对象体及根循环结束后才能判定。本轮未确认逐图层接口状态或 Map 其后全部版本字段，因而无法从参考文件安全定位根尾部，正数量根前缀的预读值仍不是已确认尾部。没有把末尾四字节或遮罩入口推断成根尾部，也未实现多 Map 循环。

## 验证和可勾范围

构造测试覆盖 0–2 版本的非空回引结构、版本 2 字符串、无接口零消费、全部截断点、未知新对象登记回退、负数及超限计数；Map 集成测试以先前登记键构造回引，仅验证流结构而不声称其实现目标接口。测试不能证明原生对象接口或运行行为。可单独勾选的是上述结构的**静态读取子集**和显式无接口零消费；完整逐图层解析、任意对象体、接口判别、Map 体结束及根尾部均不可勾选。ArcMap 10.1 运行环境暂缺；ArcMap 和 QGIS 均未进行人工打开与目视验收。未修改 TODO。
