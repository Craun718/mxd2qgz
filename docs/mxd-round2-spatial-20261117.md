## Envelope 版本 0：新的静态证据与实现

复用 Ghidra 桥接工具 全函数反编译 `/tmp/r1-pseudo-geom/functions/0x71869b60.c`：
Geometry.dll `FUN_71869b60` 首先读取 short、拒绝有符号值大于 3，随后
仅当版本等于 1 才走短分支；else 读取 32 字节、4 字节标志，依次按
bit 6、bit 7 各读取 16 字节；仅等于 3 时加载空间参考。因此版本 0
与 2 消费同一字段序列。此为 10.1.0.3035 的静态读取路径，不能说明
旧版写侧必定曾产生此布局。使用的 Geometry.dll 文件 SHA-256 为
`c57d154f207ee249adc69136574cf274771370ff93a15eb0be5682ce828f0d47`，
与既有 PE 版本记录一致；本轮核对摘要，未重新核对版本资源。

`src/objects/envelope.rs` 接受版本 0，并继续原样保留标志及可选数据；
`tests/envelope_v0_round2.rs` 测试四种标志组合、末尾边界、每个截断
前缀和失败后游标及登记表；`tests/envelope.rs` 去掉旧的版本 0 拒绝
断言。合成输入不是旧档或目标运行证据，原行 278 的样本验证仍开放。
旧 TODO 和 README 对版本 0 拒绝的描述已过时，留待整合代理更新。
