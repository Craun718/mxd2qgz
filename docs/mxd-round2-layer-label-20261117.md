## 介质候选的可复现排查

对 `temp/arcmap101-media-streams` 与 `temp/arcmap108-media-streams` 共 134 个 `.Maps` 文件按完整 16 字节 CLSID 扫描，脚本为 `temp/round2-layer-candidates.py`，从仓库根目录用 `python3 temp/round2-layer-candidates.py` 复现。它假设命中后 4 字节为键，随后两字节为版本；FeatureIDSet 再读四字节为计数。结果：

| CLSID | 候选结果（未去重） |
| --- | --- |
| FieldInfo `{A2BAAE2D-969B-11D2-AE77-080009EC732A}` | 版本 3：1007；版本 4：2014；未见 0–2 候选 |
| GroupLayer `{EDAD6647-1810-11D1-86AE-0000F8751720}` | 零命中 |
| FeatureIDSet `{D5BB4B88-E0A1-11D2-9F4D-00C04F6BC78E}` | 435 个版本 1、计数 0 候选；未见非零计数候选 |

这些命中包括重复文件和可能的回引/偶然字节序列；计数不是对象实例数量。没有扫描命中也只说明这 134 个提取流中未出现该完整字节序列，不证明所有文件或未提取流无此类。独立可确认的 FieldInfo v3 实例是既有 SouthernUSA 宿主图层循环中 `/Maps:0x931` 等 11 项，见 `mxd-layer-label-cgl-20261117.md`；参考样本 FeatureIDSet 键 75 由宿主解析到 `/Maps:0xf63`，体计数为 0。10.8 指介质来源而非磁盘或解析规则版本。

修正 `src/layers/feature_id_set.rs` 的一处说明：Load 读出的整数是 OID 候选，而非已被证明的 OID；不改变读取行为。其余未知字段保持原样。
