# Map Load 版本 34 后段与对象终点追踪（2026-11-18）

## 目标与结论

本轮把“Map Load 版本 34”按 Map 对象体中的架构版本 short=34（`0x22`）理解。目标原生函数为 ArcMap 10.1.0.3035 `Map.dll!0x793ff4d0`（Load），配对写函数为 `Map.dll!0x79401850`（Save）；地址是静态映像 VA。Map.dll SHA-256 为 `1c0675cc3a99692686a2e9dd8aaa92a68a94b48e9419d8477e33bb57634b1bb8`，本机介质提取文件与研究目录文件摘要一致。

已从反编译和随附反汇编确认 v34 的主要条件门及 Save/Load 字段方向；但**没有取得可确认 Map 架构版本为 34 的原始 `/Maps` 字节，故未闭合该版本真实对象终点**。本轮按要求没有解析版本 33（`0x21`）的对象集合。由于该循环没有外围长度，不能仅靠跳过计数项来定位后续字段。仓库参考样本及本轮检查的 10.1 介质项目均是 Map 版本 51（`0x33`），不构成 v34 字节对位证据。

## 版本 34 的门与后段字段

伪代码中的比较使用十六进制常量。按架构版本 `0x22`（34）进入时：

1. `ver > 0x20` 成立，故会经过 `0x21` 新增的计数对象循环；版本 `0x21` 本身也走这个循环。该循环由 `AfStreamRead(4)` 计数启动，随后每项 `LoadObject(..., DAT_79480bbc)`（请求 IID 为 `IUnknown`），循环后还有一个 `LoadObject(..., DAT_79488460)`。本轮不解析或推定这组对象体的大小。循环体对象没有通用外层字节长度，未知新类的对象体终点只能由其类的 Load 或受证据支持的边界得出。
2. `ver > 0x21` 成立，继续读取：`int32(+0x1d0)`、`double(+0x1d8)`、`LoadObject(DAT_79481580)`、`LoadObject(DAT_79488460)`、`double(+0x1e8)`、`int32(+0x1f0)`、`LoadObject(DAT_79487fa0)`，然后读 `short(+0x3ea)`。其中 IID 常量 `DAT_79481580`、`DAT_79488460` 在已有 Map 记录中分别按接口候选标为 IEnvelope、IMap；`DAT_79487fa0` 的接口身份和实际流内类尚未证实。
3. 因 `0x22 < 0x23`，走 `0x23` 之前的分支：读 4 字节计数；正数循环以 `LoadObject(DAT_79480bbc)` 逐项加载并调用 Map 子接口；再读 `int32(+0x1b4)`，继而 `LoadObject(DAT_79488460)`，跳回公共后段。计数项对象类由流内 CLSID 决定，IID_IUnknown 不能定出对象类。
4. 随后 `ver < 0x22` 为假，进入 `0x22` 门后的标量和对象序列；精确流序须连同 `0x793ff4d0.c` 该处外围条件逐项复查后才能编码。此处反编译可确认后继至少包括多个计数/对象槽和类请求；反编译控制流中若以 IID 标识请求、不能确定流内 CLSID 的项，仍应标为未知类，不能以 IID 充当 CLSID。

Save `0x79401850` 在相应版本分支中写入对象槽和计数，能支持 Load 的局部字段次序；它没有给整段对象体添加字节长度，也不能给任意未知对象提供可跳过边界。本轮未把未完全解析的分支概括成固定“版本 34 尾长”。

## 结论与后续可验证点

- 已证实：Map Load 10.1 接受架构版本上限 `0x33`；版本 34（`0x22`）满足 `>0x20`、`>0x21`、但不满足 `≥0x23` 的分支门。Map Save 存在相应写侧；未知对象仍由对象自身持久化实现决定体边界。
- 未证实：v34 后段在真实 MXD 中的字节起点、字段逐字节值、所有嵌套类 CLSID、任一完整 v34 Map 对象的真实终点。
- 证据缺口：可用参考/介质工程 Map 体版本均为 51；缺少 Map 体版本 34 的可信原始实例。若要保持“不碰 v33 集合”，需要先有独立证明该集合已由已闭合类体完整消费并确定其终止游标，或取得可直接从集合后起读的原生运行游标证据；本轮两者皆无。
- 本机 REA CLI 不可用时，后续若定向补导，应请求 `Map.dll!0x793ff4d0`、`Map.dll!0x79401850`，并对未知对象类按实际 CLSID 分别定位其 `IPersistStream::Load/Save`，不应只请求整个 Map 模块或以 IID 代替类标识。
